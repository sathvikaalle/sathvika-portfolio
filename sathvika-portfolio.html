Case study

Designing the authenticated core of a platform for capstone coordinators across Australasia

UI/UX & Authentication Developer, within a six-person Agile team. Real external client — university capstone-course coordinators across Australia and New Zealand. 2026, ongoing.

The problem

Capstone coordinators across different universities had no shared place to find each other, share project models, or coordinate across institutions. Our client asked for a web platform that could support registration, member profiles, and role-based authenticated functionality for a growing, distributed user base — not a marketing site, but a working tool people would return to.

Research and requirements

Requirements came from regular meetings with the client, not a brief handed to us upfront. I translated what coordinators told us they needed — clear onboarding, trustworthy authentication, an easy way to find and manage their own listings — into concrete interface decisions, then checked those decisions against the client's feedback each iteration.

Design system and components

I designed and maintain the platform's reusable UI components and page structures in Figma, so the six of us could build new features without reinventing patterns each time. Registration, login, and profile screens all draw from the same component set.

Add: Figma component library or design system screenshot A screenshot of your Figma file showing the reusable components (buttons, form fields, cards, nav) as a set — this is the single most convincing image for a role that explicitly asks about "flexible, reusable UI components."

From design to build

I own UI/UX and authentication end to end, which means I also see designs through to the React front end, integrated with AWS Cognito. Working this close to implementation shaped how I design — I know what's easy to build responsively and what isn't, and I design with that in mind rather than handing off screens I haven't tested against the real constraints.
